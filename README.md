# MediCare frontend preview

This project now includes a standalone, responsive browser frontend in `index.html`. It uses HTML, CSS, and JavaScript with sample data; it does not need Maven, JavaFX, a database, or a web server.

## Open the frontend

Open `index.html` in a browser, or open this folder in VS Code and use **File → Open File** to open `index.html`, then choose **Open in Default Browser** if that command is available.

The dashboard includes interactive navigation, patient search, sample hospital sections, and forms for adding patients and appointments. Data is kept only in the current browser page and is not connected to PostgreSQL.
